01 // Selected Projects

Featured Project // Project Lead & Lead Dev

HEXILEXI – AI WORD DETECTIVE

An LLM-driven vocabulary trainer for primary school readers, built as a custom React component inside the university's public STREEN platform.

  • • A two-step "Architect and Builder" prompt pipeline runs on local Ollama instances with Gemma 3:12b.
  • • Answers are graded in the browser with Levenshtein distance instead of extra LLM calls.
  • • UI state-locking and request queues keep the app stable when a whole class uses it at once.
  • • Tested over four iterations in two primary schools.

Active Research // ZAT

ADHD READING ASSISTANT

A pro-adaptive reading support system for people with ADHD, developed with ZAT and Rhine-Waal University.

  • • The adaptive control logic (Dynamic Support Index) maps reading speed and medication trajectory onto five levels of visual support.
  • • Tobii eye-tracking feeds the system through a Lab Streaming Layer data stream.
  • • PDF, EPUB, and web parsing pipelines (Docling, PyMuPDF4LLM) prepare documents for LLM-based text simplification.
  • • The desktop interface is built in PySide6/Qt with Pygame visualisations.
Python Pygame PySide6 PyMuPDF4LLM Docling
Open Source // Maintainer

MOVELLA DOT → LSL PIPELINE

A real-time IMU streaming pipeline maintained for ZAT Rhine-Ruhr, published as open source.

  • • Streams 16 channels at 30 Hz from Movella DOT sensors over BLE into Lab Streaming Layer.
  • • Ships example viewers, diagnostic tools, and setup documentation for Ubuntu 22.04 and Windows.

Academic Project // Solo Developer

HSRW RAG CHATBOT ("ZERO")

An advisor system that answers questions about curriculum details, schedules, and module handbooks from local hardware.

  • • Indexed 500+ pages of academic PDF regulations with ChromaDB vector search.
  • • Intent routing with LangChain and Ollama (Llama 3.2) returns hybrid BM25 and vector answers.
  • • Packaged as an interactive chat interface on Gradio 6.0.
