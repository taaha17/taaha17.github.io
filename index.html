ADHD Reading Assistant

2026—
Research at ZAT Rhine-Ruhr / Python, PySide6/Qt, Tobii LSL, Docling

People with ADHD experience elevated cognitive effort and attention fluctuations when reading digital text that static font settings cannot address. I implemented the closed-loop pro-adaptive control layer (Section 3.2 of our MuC 2026 paper), which drives a single continuous parameter—the Dynamic Support Index, DSI ∈ [0, 1]—so visual support scales up as fatigue grows and recedes as focus recovers.

Attentional state
Tracks reading velocity over a 60 s rolling window (updated every 5 s) against a calibrated 3-minute baseline, filtering out scroll/cursor movement, >8 s idle gaps, and >550 wpm skimming.
Pharmacodynamics
Approximates expected therapeutic concentration from hours since intake using peak-normalised first-order absorption and elimination kinetics across immediate-, extended-, and osmotic-release profiles.
Hysteresis & 5 tiers
Smooths raw DSI with an exponential moving average (α = 0.1) and a ±3% dead-band before stepping across plain text, bionic font, line highlight, high-contrast word highlight, and peripheral blur.

Built in PySide6/Qt with Tobii gaze streaming over Lab Streaming Layer and document parsing via Docling and PyMuPDF4LLM. Evaluated in a heuristic and think-aloud study with five UX/UI professionals who have ADHD, reaching a mean SUS score of 88.50.

HexiLexi

2025—2026
Project lead & lead developer, STREEN at LeseLab / React, Gemma 3:12b, Ollama

An inquiry-based vocabulary companion embedded as a modular React component inside the STREEN digital reading platform for LeseLab. Instead of handing children passive dictionary definitions, it guides 8-to-10-year-olds through four state-machine modes (Explain, Discover, Synonym, and German compound Word Parts) using a local Gemma 3:12b model on Ollama.

Tested across four classroom sessions in two primary schools. Migrating from Llama 3.3 (30–45 s latency) to Gemma 3:12b and splitting one monolithic prompt into a two-step pipeline made classroom response times viable.

System pipeline (Section 3 of project report)
01Architect promptAnalyzes the clicked word in sentence context and outputs JSON (meaning, hints, distractors, synonyms).
02Builder promptDrives the active mode's multi-turn state machine using the Architect's JSON payload.
03Browser graderGrades typed or German Web Speech answers via exact, substring, and Levenshtein similarity.
04Request queueQueues requests and locks UI state with AbortController timeouts so classroom button-spamming never crashes the API.
Model: Gemma 3:12b on a local AIS Lab Ollama instance.4 iterations in 2 primary schools (N = 38)
